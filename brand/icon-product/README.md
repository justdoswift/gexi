# gexi — 从产品出发的图标方向

方法沿用 [design-playful-app-icons](https://github.com/chunkithwang/design-playful-app-icons)：
先写 `物体 + 动作 + 情绪`，选一条视觉路线，出三个真正不同的方向，评分后再生产。
这一轮不预设蛇（上一轮 `brand/playful/` 的蛇方案已作废），只从产品本身推导。

## 产品事实 → 三个方向

gexi 真实做的事只有几件：项目里开会话、会话切成任意嵌套的窗格、几个 agent 同时跑、
关掉窗口它们还在跑、外面的 CLI 能驱动整个窗口。

| # | 名字 | 路线 | 隐喻 | 轮廓 | 32 px |
|---|---|---|---|---|---|
| A | 窗格 | Minimal dimensional glyph | 工作区本体：一块窗格切成三块 | 圆角窗格里的不对称分栏 | 一个窗格，右下角发亮 |
| B | 分叉 | Minimal dimensional glyph | 一个 shell 分出三个并行会话 | 主干 + 三分支，末端是窗格 | 一根茎顶着三块 |
| C | 嵌套 | Minimal dimensional glyph | 窗格套窗格，可以一直分下去 | 三层递进，向内收 | 一个方块里一个点 |

评分（按 skill 的 100 分 rubric）：**A 84 · B 91 · C 80**。

**推荐 B（分叉）**。
- 它讲的是产品最有价值的那件事：一个 shell，几个会话并行，聚焦的那个在跑。
- 小尺寸最稳：16 px 下仍是一根茎顶三块，不会退化成"又一个窗口图标"。
- A 最直白，但也最像通用的窗口/布局图标，Dock 里不占优势。
- C 最安静，可它是"一个方块"，含义要靠解释。

## 生产文件（B）

```
final/
  gexi-icon.svg          1024 满幅图标（纸白渐变底 + 标记）
  gexi-mark.svg          标记单层，透明底
  gexi-mark-mono.svg     单色版（强调色并入墨色）
  png/                   1024 512 256 180 120 60 32 16
preview.png              三方向对比图
renders/                 各方向 1024 渲染
```

### 规格

- 底：`#F8F6F5 → #EEEAE4`，135°，两段，安静背景。
- 主体：`#121212`，笔画 86（占画布 8.4%），圆头。
- 强调：`#AC46EA`，只给聚焦的那个窗格（它同时被抬高 30 px）。
- 三个窗格 176×176、圆角 46；分叉曲线末端扎进窗格中心，圆头被窗格完全盖住。
- 标记边界 x 179–845、y 112–912，四周留白 11%–17%。

### 小尺寸

- 1024 / 180：三条分支和三个窗格都清楚，聚焦窗格的紫色是唯一高饱和点。
- 60：窗格与茎仍分得开，紫色还是一眼能看见。
- 32：读成"茎 + 三块"，紫色在顶上。
- 16：只剩轮廓和紫色顶块；可接受，16 px 只承担识别。

## 原创性

没有引用任何现成标志、角色或艺术家风格。三个方向都从产品动作（分屏、并行会话、
递归分割）推导，形态是圆角窗格 + 粗圆头笔画，属于通用几何语汇，不针对任何具体品牌。
